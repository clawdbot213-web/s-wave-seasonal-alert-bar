## Long description
Seasonal Alert Bar helps you announce promotions, shipping cutoffs, new arrivals, or store updates in minutes. Add a clean banner to your storefront—top or bottom—using Shopify’s theme editor. Choose a preset, set a schedule, and publish.

**Why merchants choose Seasonal Alert Bar:**
- Launch seasonal promos fast with ready-to-use presets
- Schedule start/end times so you never forget to turn it on/off
- Add a CTA button to drive traffic to a collection or product
- Match your brand with color and layout controls
- Let visitors dismiss the bar to keep browsing smooth

Built to be lightweight and theme‑safe—no code required.

## Key features
- Theme app block (top/bottom placement)
- Preset styles: Holiday, Announcement, Minimal, Dark, Custom
- Scheduling (start/end time)
- CTA button (solid/outline)
- Dismissible alerts with duration controls

## Data handling
- **Customer data stored:** None
- **Store data stored:** App configuration only (bar settings)

## Review instructions (for Shopify)
1. Install the app in a dev store.
2. Open **Online Store → Themes → Customize**.
3. Add the **Seasonal alert bar** app block.
4. Adjust message, CTA, and schedule. Save.
5. Verify the bar appears on the storefront.
